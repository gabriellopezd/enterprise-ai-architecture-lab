# Public source register

This Proof of Work uses a deliberately small, curated set of claims from official public documentation. The source text is paraphrased into learning evidence; it is not presented as a complete registry or authoritative comparative assessment.

| System | Official source | Bounded public claim used |
| --- | --- | --- |
| GOV.UK One Login | https://docs.sign-in.service.gov.uk/ | Government services can use One Login to sign in users and prove identity. |
| Login.gov | https://www.login.gov/about-us/ | Login.gov provides secure access to participating government sites and supports identity verification. |
| Singpass | https://developer.singpass.gov.sg/ | Singpass supports authentication, consent-based Myinfo data sharing, and electronic signing. |
| X-Road | https://x-road.global/x-road-technology-overview | X-Road provides standardized secure data exchange and interoperability capabilities. |

## Source boundary

The evidence statements are intentionally narrow and traceable to the URLs above. No private organization, customer, employer, Intellecto, ArquiFácil, AEther, or MJD information is used.
