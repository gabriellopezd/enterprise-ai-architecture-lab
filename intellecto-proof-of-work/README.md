# INTELLECTO Proof of Work

This directory is the public capstone layer of the Enterprise AI Architecture Lab.

An **INTELLECTO Proof of Work (IPOW)** is not a course exercise and is not a replacement for the underlying technical Proofs of Work. It composes verified credentials, immutable evidence, architectural reasoning and explicit claim boundaries into one navigable professional artifact.

## Namespace

- `POW-<TECH>-NNN` — technical learning/evidence milestone.
- `IPOW-NNN` — cross-milestone portfolio capstone.
- Credentials are referenced by their own credential IDs and are never numbered as courses.

## Lifecycle

```text
PLANNED
  → BUILD_PENDING
  → IN_REVIEW
  → VERIFIED
  → PUBLISHED
```

A capstone reaches `VERIFIED` only after its evidence references, claims boundary, privacy boundary and repository validation all pass.
