# AI-Assisted Coding Evidence Track

This directory contains public, sanitized technical evidence for learning milestones focused on using generative AI to support software-code generation and then validating the resulting code through human review, execution and automated tests.

| PoW | Learning milestone | Public path | Status |
| --- | --- | --- | --- |
| POW-AICODING-001 | SENA — Generación de códigos de software con inteligencia artificial | `ai-assisted-coding/01-python-logic-validation` | AWAITING_CREDENTIAL |

## Capability progression

```text
understand problem
  → express logic
  → prompt / generate
  → review code
  → execute
  → test branches and boundaries
  → preserve evidence
```

Academic submissions, Zajuna records, personal data and issuer documents remain outside this public repository.

Validation gate: the milestone is not merged until its pull-request runtime validation reports `VALIDATION_RESULT=PASS`.
